# Create – Shopify テーマ

日本語ショップ向けの Shopify **Online Store 2.0** テーマです。
外部ライブラリに依存しない軽量な構成で、テーマエディタからノーコードでカスタマイズできます。

## 主な機能

| ページ | 内容 |
| --- | --- |
| トップ | メインビジュアル / おすすめ商品 / コレクション一覧 / 画像とテキスト / テキスト（すべてテーマエディタで並び替え・追加可能） |
| 商品詳細 | 画像ギャラリー、バリエーション選択（価格・画像・在庫が連動）、数量選択、カート追加、スピードチェックアウト、折りたたみ情報、シェア、関連商品、構造化データ |
| コレクション | 絞り込み（Search & Discovery 対応）、並び替え、ページネーション |
| カート | 数量変更（自動更新）、注文メモ、割引表示、追加チェックアウトボタン |
| その他 | 検索、ブログ / 記事、固定ページ、お問い合わせ（`page.contact`）、404、パスワードページ、ギフトカード |
| 会員 | ログイン / 新規登録 / マイページ / 注文詳細 / 住所管理 / パスワード再設定（クラシック顧客アカウント） |

エディトリアル系セクション（テーマエディタで追加可能）：ブランドヒーロー（単色背景＋大きなタイトル）/ ルックブック / ルックから買う / ピックアップ・スライド / ブランドストーリー（画像＋テキスト枠）/ 同じブランドの商品

共通：ヘッダー（ロゴ中央・メガメニュー・国/通貨セレクター対応）（固定表示・スマホ用ドロワーメニュー・ドロップダウン）、お知らせバー、フッター（メニュー / テキスト / メルマガ登録 / SNS / 決済アイコン / ポリシー）。

## ディレクトリ構成

```
layout/      theme.liquid（共通レイアウト）、password.liquid
templates/   各ページの JSON テンプレート、customers/（会員ページ）
sections/    テーマエディタで編集できるセクション（header-group / footer-group を含む）
snippets/    商品カード・価格・アイコンなどの部品
assets/      base.css / theme.js
config/      テーマ設定（カラー・フォント・レイアウト・SNS など）
locales/     ja.default.json（既定）/ en.json
```

## セットアップ

1. [Shopify CLI](https://shopify.dev/docs/api/shopify-cli) をインストール

   ```bash
   npm install -g @shopify/cli
   ```

2. ローカルでプレビュー（開発ストアに接続されます）

   ```bash
   shopify theme dev --store your-store.myshopify.com
   ```

3. テーマの静的チェック

   ```bash
   shopify theme check
   ```

4. ストアへアップロード（未公開テーマとして追加）

   ```bash
   shopify theme push --unpublished --store your-store.myshopify.com
   ```

   管理画面の「オンラインストア > テーマ」からプレビュー・公開してください。
   GitHub 連携（管理画面の「テーマを追加 > GitHub から接続」）を使うと、このリポジトリへの push が自動でストアに反映されます。

## ストア側で行う設定

- **メニュー**：「コンテンツ > メニュー」で `main-menu`（ヘッダー）と `footer`（フッター）を作成
- **コレクション**：トップページの「おすすめ商品」「コレクション一覧」にテーマエディタから割り当て
- **お問い合わせページ**：固定ページを作成し、テンプレートに `contact` を選択
- **絞り込み**：Shopify 公式アプリ「Search & Discovery」でフィルター項目を設定
- **カラー・フォント・SNS**：テーマエディタの「テーマ設定」から変更

## 商品情報（メタフィールド）

商品ページの「商品詳細」「サイズ（実寸）」の表は、商品ごとのメタフィールドから自動で作られます。空欄の項目は表示されません。
ブランドは「販売元」、管理番号は「SKU」の欄を使います。

管理画面の「設定」→「メタフィールドとメタオブジェクト」→「商品」→「定義を追加」で、次の定義を作成してください（「名前空間とキー」は表のとおり正確に入力）。

| 名前 | 名前空間とキー | タイプ |
| --- | --- | --- |
| コンディション | `custom.condition` | 単一行テキスト（「プリセット値のリストに制限」で S / A / AB / B / C） |
| 状態の詳細 | `custom.condition_notes` | 複数行テキスト |
| 表記サイズ | `custom.size_label` | 単一行テキスト |
| 素材 | `custom.material` | 単一行テキスト |
| 毛皮の種類 | `custom.fur_type` | 単一行テキスト |
| カラー | `custom.color` | 単一行テキスト |
| 付属品 | `custom.accessories` | 単一行テキスト |
| 原産国 | `custom.origin` | 単一行テキスト |
| 着丈 | `custom.length` | 単一行テキスト |
| 身幅 | `custom.chest` | 単一行テキスト |
| 肩幅 | `custom.shoulder` | 単一行テキスト |
| 袖丈 | `custom.sleeve` | 単一行テキスト |
| ウエスト | `custom.waist` | 単一行テキスト |
| ヒップ | `custom.hip` | 単一行テキスト |
| 股下 | `custom.inseam` | 単一行テキスト |
| 総丈 | `custom.total_length` | 単一行テキスト |
| その他の実寸 | `custom.measurements_other` | 複数行テキスト |

- 実寸は数字だけ入力すれば、表示時に「cm」が付きます（例：`68` → 68 cm）。
- コンディションのランクの説明文は、テーマエディタの商品ページ →「商品詳細（表）」ブロックで変更できます。
